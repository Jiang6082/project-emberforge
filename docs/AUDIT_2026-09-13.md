## Interpretation and compatibility

- With declared gross=1, the portfolio backtest invests 0.5 long and 0.5 short.
  A top-minus-bottom diagnostic has gross=2; these are different return streams.
  Neither is a next-open execution simulation. Geld independently tests an
  explicit executable construction.
- Data fingerprints change because they now bind more identity metadata.
  Preserve old registry entries as historical evidence; do not rewrite them to
  imply equivalent inputs. Changed masks, signs, costs and multiplicity may
  change verdicts. Existing market results need new runs before comparisons.
- Automatic exports retain `auto_approved`, describing development screening,
  not human sign-off or independent holdout success. `--no-approve` produces
  reports only; the native export API supports explicit human approval.

## Remaining work and required evidence

1. **Persistent prospective protocol.** The fractional holdout is respected for
   each supplied dataset. Fixed dates across appended datasets, revisions,
   reruns and family renaming still need a persistent protocol. Changing family
   or output directory does not reset the scientific number of attempts.
2. **Statistical dependence and horizons.** IC t-statistics and simple Sharpe
   evidence use IID approximations. Overlapping multi-bar labels, serial
   correlation and dependent tests need horizon-aware/HAC or block-bootstrap
   calibration. Daily annualization is not valid for intraday or overlapping
   multi-day returns treated as independent daily observations. Low-level
   analytics remain diagnostic outside the daily, one-bar setting.
3. **Robustness in promotion.** White RC, SPA, PBO, CPCV and stability are
   reported, but not all are mandatory gates. Introduce a versioned,
   pre-registered policy and calibrate it on null and planted-signal simulations
   before claiming stronger error control.
4. **Independent real-data validation.** Re-run corrected factors on dated PIT
   membership, multiple feeds, corporate actions, delistings and real cost/
   borrow evidence. No external market-history download, account or order was
   used here. Synthetic acceptance tests are software evidence.
5. **Portfolio/capacity realism.** The portfolio remains a daily target-weight
   approximation without drift-adjusted holdings, fills, financing, borrow
   recalls or venue-calibrated impact. Capacity uses a trailing liquidity
   snapshot. Real held-name missing returns need an explicit valuation/delisting
   policy rather than dropping difficult observations.
6. **Complete trial/lineage governance.** Some failed LLM requests and invalid
   pre-FactorSpec proposals are skipped. Persist them and resolve ancestry
   between factor IDs and experiment IDs. Add atomic candidate-budget
   reservations and immutable per-run output directories before supporting
   concurrent research; atomic holdout reservations are not a scheduler.
7. **Complete interop fixtures.** Independent evaluators now agree on the
   current operators. Freeze fixtures for membership, missing-data semantics,
   preprocessing, construction and timing too. A checksum establishes internal
   consistency, not authorship or scientific merit.
8. **Release reproducibility and optional integrations.** Add release-specific
   dependency locks and content-addressed input snapshots. CI exercises declared
   compatible ranges. Optional LLM-provider behavior requires credentials and a
   test budget and was not exercised here.
